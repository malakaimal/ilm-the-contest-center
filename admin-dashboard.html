Individual record entry

Need to add only one student? Use the individual result form below. For a whole class, use the bulk upload above.
How to publish results: Find the student's Registration ID in the Registered Students table. Enter that ID and the student's details below, add the score and total marks, then tick Publish this result publicly before selecting Save Result. If the box is not ticked, the result remains unpublished. Students can search published results on the Results page and see their own records in the Student Portal.
