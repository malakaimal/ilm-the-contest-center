ADMIN WORKFLOW

Prepare and publish a test

01

Create a session

Add a unique Test ID, title, class, schedule, duration and instructions in Test Sessions.

02

Add questions

Add each MCQ in Test Questions. Keep the correct option in the admin-only spreadsheet.

03

Assign students

Add each student's Registration ID, Test ID, unique access code and Assigned status.

04

Publish and review

Publish only when ready, then review submissions and results after the test.

SECURITY & STUDENT PRIVACY

Before enabling live exams

The current backend is an early foundation, not a production-secure examination service. Admin authentication, exam-window enforcement, stronger student verification and server-side request validation must be completed before public deployment. Camera and screen checks are not AI monitoring, and this version does not record or upload video.
