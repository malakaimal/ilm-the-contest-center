ILM Management

Exam Administration

Manage examination sessions, student assignments, question banks and results using the separate ILM Exam Database.

Database setup

Create the new spreadsheet by running setupExamDatabase() in the separate Google Apps Script project. The script returns the spreadsheet link in its execution log.

Open Google Apps Script

Admin workflow

  1. Create a test session in Test Sessions.
  2. Add questions in Test Questions.
  3. Assign students in Student Test Access.
  4. Publish the session by setting Status to Published.
  5. Review Student Responses and Test Results.

Important security note

Do not publish this page as an admin login or place a private admin password in browser JavaScript. Restrict spreadsheet sharing to authorized ILM administrators. This initial release does not yet provide a secure online admin editing interface or AI proctoring.
